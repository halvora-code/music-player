# music-player

What it is: A player that plays a few songs with a working pause, next, and previous button. 

How I did it: This project included a LOT of JavaScript. I am still new to JavaScript so I of course could not build this on my own. I did a lot of research and followed tutorials on how I could accomplish the functioning of the music player and the music player bar. I followed most of the tutorial to code the back end but when it came to the U.I design I wanted to do it myself.

The tutorial I followed:

What I learned: In all honesty I would not be able to code all of the JavaScript again from the top of my head. Some things stuck but some things I still need to practice with. I learned a little about functions and how they work. I learned how to find the console in a website and how to use it to find bugs in the code.


Some challenges: Doing this project makes me want to learn more JavaScript. I used more div elements in HTML and learned how they connect to the JavaScript. I made a lot of mistakes with this project, I spent a good amount of time debugging and majority of the problems were incorrect spelling for tags and variables.
